 🚀 Lalit Gonji — Portfolio Website

Personal portfolio for Lalit Gonji, an AI data engineer in Sydney. The live site updates only after this repository is redeployed.

## 🔗 Live Site
> Deploy to [Netlify](https://netlify.com/drop) by dragging the folder — live in seconds.

---

## ✨ Features

- Dark / Light mode toggle
- Animated particle hero section
- Scroll reveal animations
- Fully responsive (mobile, tablet, desktop)
- 6 projects showcase
- Contact form
- Smooth navigation with active section highlighting

---

## 🧰 Built With

`HTML5` · `CSS3` · `Vanilla JavaScript` · `Font Awesome` · `Google Fonts`

No frameworks. No build tools. Just open and run.

---

## 📁 Project Structure

```
portfolio/
```
