 🚀 Lalit Gonji — Portfolio Website

Personal portfolio website showcasing my projects, skills, and experience as a Full Stack Software Engineer based in Sydney, Australia.

## 🔗 Live Site
> Deploy to [Netlify](https://netlify.com/drop) by dragging the folder — live in seconds.

---

## ✨ Features

- Dark / Light mode toggle
- Animated particle hero section
- Scroll reveal animations
- Fully responsive (mobile, tablet, desktop)
- 6 projects showcase
- Contact form
- Smooth navigation with active section highlighting

---

## 🧰 Built With

`HTML5` · `CSS3` · `Vanilla JavaScript` · `Font Awesome` · `Google Fonts`

No frameworks. No build tools. Just open and run.

---

## 📁 Project Structure

```
portfolio/
├── index.html          # Home — Hero, About, Skills, Experience, Education
├── projects.html       # All 6 projects
├── contact.html        # Contact page with form
├── styles/
│   └── main.css        # All styles
├── js/
│   └── main.js         # Animations, theme toggle, particles
└── assets/
    └── lalit.jpg       # Profile photo
```
